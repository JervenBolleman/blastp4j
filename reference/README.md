# BLAST+ reference results

`src/test/resources/reference` holds the output of NCBI BLAST+ that blastp4j is checked against. Regenerate with
`reference/make_reference.sh`.

| File | blastp options | Hits |
|---|---|---:|
| `human_vs_sprot.cbs2.tsv.gz` | defaults (composition-based statistics mode 2) | 11,263 |
| `human_vs_sprot.cbs0.tsv.gz` | `-comp_based_stats 0` | 15,107 |
| `human_vs_sprot.ungapped.tsv.gz` | `-comp_based_stats 0 -ungapped` | 27,246 |

`ungapped_karlin.tsv` holds blastp's ungapped lambda, K and H of each query (the first "Lambda K H" line of its text
report), regenerated by `reference/ungapped_karlin.sh`.

* Queries: the 24 human UniProtKB/Swiss-Prot proteins in `src/test/resources/queries/uniprot_human.fasta` (103 to
  1,863 residues), the same set as the cssw4j test dataset.
* Database: UniProtKB/Swiss-Prot release 2026_03 (02-Sep-2026), 575,748 sequences, built with
  `makeblastdb -dbtype prot -parse_seqids`.
* BLAST+ 2.17.0 (`blastp: 2.17.0+`, build Jul 1 2025), `-num_threads 1`.
* Columns (`-outfmt`): `qseqid sseqid pident length mismatch gapopen qstart qend sstart send evalue bitscore score qlen
  slen btop`.
* Time on the development machine (i7-6700HQ, one thread): 80 s with composition-based statistics, 76 s without and
  52 s ungapped, for the 24 queries.

## blastp defaults these runs use

From the exported search strategy (`-export_search_strategy`): word threshold 11, two-hit window 40,
composition-based statistics 2, SEG off, e-value cutoff 10. From the BLAST+ documentation for task `blastp`: word size
3, BLOSUM62, gap open 11, gap extend 1, X-drop 7 bits (ungapped), 15 bits (preliminary gapped), 25 bits (final
gapped), max_target_seqs 500.

## SEG test data

`src/test/resources/seg/sprot_sample.fasta.gz` holds 400 Swiss-Prot 2026_03 sequences (every 50th of the first
20,000) and `sprot_sample.segmasker.txt.gz` the intervals BLAST+ 2.17.0 masks in them with the parameters of
composition-based statistics:

    segmasker -in sprot_sample.fasta -infmt fasta -window 10 -locut 1.8 -hicut 2.1 -outfmt interval

## Composition adjustment test data

`src/test/resources/compo/adjust_cases.txt.gz` holds 306 pairs of query and subject compositions (as hexadecimal
doubles), and `adjust_blast.txt.gz` the result of BLAST+'s `Blast_AdjustScores` for each: status, adjustment rule,
lambda ratio and the adjusted 28 x 28 matrix. They were computed by `reference/compo/build_harness.sh`, which builds
`reference/compo/harness.c` against the composition adjustment library downloaded from the NCBI C++ Toolkit sources.

## Command line test data

`src/test/resources/cli` holds blastp's output for the 24 queries against the 400 sequences of the SEG sample
(`src/test/resources/seg/sprot_sample.fasta.gz`), after `makeblastdb -in sample.fa -dbtype prot -parse_seqids`:

    blastp -query uniprot_human.fasta -db sample -outfmt "6 std btop" > sample_std_btop.tsv
    blastp -query uniprot_human.fasta -db sample -comp_based_stats 0 -evalue 1000 -max_target_seqs 20 \
        -outfmt "6 qseqid sseqid qcovhsp ppos positive gaps nident evalue bitscore score" > sample_cbs0_e1000.tsv

## BLAST database test data

`src/test/resources/blastdb` holds small databases made by makeblastdb 2.17.0, for reading `.pin`, `.psq`, `.phr`
and `.pal` files and for printing identifiers of every kind; its README gives the commands and the blastp runs that
made the expected outputs.
